# Deliverables

This folder organizes the seven deliverables defined in the NHN Healthcare Consulting Engagement Packet.

Each deliverable folder uses the same working structure:

- `analysis/`: calculations, scripts, model results, or analytical writeups.
- `data/`: deliverable-specific source extracts, summary tables, and supporting CSV files.
- `images/`: charts, dashboard screenshots, visual assets, and slide-ready graphics.
- `notes/`: working notes, assumptions, reviewer comments, and talking points.
- `drafts/`: working versions of reports, dashboards, slides, or document drafts.
- `final/`: final submitted files.

## Deliverable Folders

1. `01_project_charter`
2. `02_eda_report`
3. `03_model_evaluation_report`
4. `04_clinical_care_coordination_report`
5. `05_financial_impact_roi_report`

## Source Of Truth

- Use `PROJECT_SUMMARY.md` and `checklist.md` for project requirements.
- Use `data/processed/nhn_patient_level_analysis.csv` as the primary integrated analysis dataset.
- Use section-level assets under `sections/` as reusable evidence for the deliverables.
