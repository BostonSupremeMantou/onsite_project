# Deliverable 3: Model Evaluation Report

## Purpose

Compare predictive models that identify patients at high risk of 30-day readmission and explain how leadership should use the model.

## Required Contents

- Baseline model.
- Advanced or expanded model.
- Rationale for model selection.
- Accuracy, precision, recall, F1 score, ROC-AUC, and confusion matrix.
- Feature importance or coefficient interpretation.
- Model limitations.
- Business and clinical implications.

## Recommended Supporting Inputs

- `sections/05_predictive_modeling_results/data/model_metrics.csv`
- `sections/05_predictive_modeling_results/data/model_feature_importance.csv`
- `sections/05_predictive_modeling_results/images/`
- `sections/05_predictive_modeling_results/notes/predictive_modeling_findings.md`

## Output Target

Create a model evaluation report in `final/` and retain modeling outputs in `analysis/`.
