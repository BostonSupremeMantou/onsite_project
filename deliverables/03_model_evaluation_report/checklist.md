# Model Evaluation Report Checklist

- [ ] Define modeling objective.
- [ ] Define target variable.
- [ ] List included and excluded features.
- [ ] Explain train/test split or validation approach.
- [ ] Report baseline model performance.
- [ ] Report expanded or advanced model performance.
- [ ] Compare model metrics.
- [ ] Include confusion matrix.
- [ ] Include feature importance.
- [ ] Explain model limitations.
- [ ] Recommend operational use and threshold considerations.
- [ ] Move final report to `final/`.
