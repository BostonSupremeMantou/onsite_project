# Project Charter Draft

## Business Problem Statement

National Hospital Network is experiencing rising 30-day hospital readmissions, creating clinical, operational, and financial pressure.

## Project Objectives

1. Identify drivers of readmission risk.
2. Build predictive models for patient risk identification.
3. Evaluate care coordination effectiveness.
4. Estimate financial impact and ROI.
5. Build executive dashboard assets.
6. Develop strategic recommendations for the Board.
