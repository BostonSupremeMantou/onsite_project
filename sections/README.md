# Presentation Section Workspace

This folder organizes the project by final Board presentation section.

Each section folder uses the same structure:

- `analysis/`: calculations, notebooks, model outputs, and written findings for the section.
- `data/`: section-specific source extracts, summary tables, or dashboard-ready CSVs.
- `images/`: charts, dashboard screenshots, diagrams, and presentation visuals.
- `notes/`: talking points, slide notes, assumptions, and draft recommendation language.

Use `data/processed/nhn_patient_level_analysis.csv` as the primary integrated analysis dataset unless a section needs a narrower extract.
