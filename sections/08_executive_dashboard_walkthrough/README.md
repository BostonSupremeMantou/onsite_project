# 08 Executive Dashboard Walkthrough

## Purpose

Prepare the Tableau dashboard materials and walkthrough narrative for executive decision-making.

## Content To Prepare

- Executive KPI Summary.
- Clinical Analytics view.
- Financial Analytics view.
- Care Coordination Analytics view.
- Executive Recommendation Center.
- Dashboard walkthrough script.

## Evidence Needed

- Readmission rate.
- Patient risk score.
- Total care cost.
- CMS penalties.
- ROI.
- High-risk patient count.
- Intervention completion rates.
- Expected savings by scenario.

## Folder Use

- `analysis/`: dashboard metric definitions and QA checks.
- `data/`: dashboard-ready extracts.
- `images/`: dashboard screenshots and annotated walkthrough visuals.
- `notes/`: demo script and dashboard interaction notes.
