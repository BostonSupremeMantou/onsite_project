# 03 Data Overview

## Purpose

Describe the source datasets, integration method, data quality issues, and preparation process.

## Content To Prepare

- Overview of the patient readmission dataset.
- Overview of the financial impact dataset.
- Overview of the care coordination dataset.
- Explanation of `patient_id` as the join key.
- Data cleaning process.
- Data limitations and quality issues.

## Evidence Needed

- Row counts and unique patient counts.
- Join integrity summary.
- Missing value summary.
- Negative financial value flags.
- Cleaning rules from `DATA_CLEANING_SUMMARY.md`.

## Folder Use

- `analysis/`: profiling notes and data quality checks.
- `data/`: data dictionary extracts and data quality tables.
- `images/`: data flow diagram, missing value visual, or source overview graphic.
- `notes/`: wording for data limitations and preparation methodology.
