# 07 Financial Impact Analysis

## Purpose

Quantify the current financial burden associated with readmissions and identify where cost exposure is concentrated.

## Content To Prepare

- Current readmission costs.
- CMS penalty exposure.
- Total care costs.
- Resource utilization impact.
- Expected savings opportunity.

## Evidence Needed

- Total care cost by readmission outcome.
- Penalty cost summary.
- Net reimbursement gap.
- Cost by diagnosis, risk segment, discharge disposition, and intervention status.
- Cost difference between readmitted and non-readmitted patients.

## Folder Use

- `analysis/`: financial baseline calculations and cost driver analysis.
- `data/`: financial summary tables and cost segment extracts.
- `images/`: cost exposure charts and financial impact visuals.
- `notes/`: financial interpretation and caveats.
