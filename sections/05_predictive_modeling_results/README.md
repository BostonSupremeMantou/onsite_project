# 05 Predictive Modeling Results

## Purpose

Show how NHN can identify high-risk patients before discharge using explainable predictive modeling.

## Content To Prepare

- Baseline model results.
- Advanced model results.
- Model comparison.
- Final model selection.
- Feature importance.
- Clinical interpretation.
- Model limitations.
- Operational use case for leadership.

## Evidence Needed

- Modeling feature set.
- Train/test split or cross-validation design.
- Accuracy, precision, recall, F1 score, ROC-AUC, and confusion matrix.
- Feature importance or coefficient interpretation.
- Recommended high-risk threshold.

## Folder Use

- `analysis/`: modeling scripts, outputs, and evaluation notes.
- `data/`: modeling datasets, predictions, and metrics tables.
- `images/`: ROC curves, confusion matrices, feature importance charts, and risk segmentation visuals.
- `notes/`: model explanation, limitations, and executive interpretation.
