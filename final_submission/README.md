## Visual Assets

Each deliverable folder includes an `images/` directory with the figures used in that report. The final Markdown reports keep the same `final/` plus `images/` structure as the working deliverable folders, so image links should render correctly when opened from this package.

## Recommended Review Order

1. Open `07_executive_board_presentation/final/nhn_readmission_board_presentation.pptx`.
2. Review `06_executive_dashboard/final/nhn_dashboard_build_package.xlsx` and the Tableau build guide.
3. Review the written reports in folders `01` through `05`.
4. Use `00_project_evidence/REPORT_EVIDENCE_AUDIT.md` to verify references, figures, and core metrics.

## Notes

- The required dashboard direction is Tableau. The included workbook is the Tableau build package, not a native `.twb` or `.twbx` file.
- Final reports include figures generated from the cleaned project data.
- References and evidence rules are included in `00_project_evidence/`.
